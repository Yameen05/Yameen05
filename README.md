## 🚀 Featured Projects

### [Trimly](https://github.com/Yameen05/Trimly) — Barbershop Booking Platform

Full-stack barbershop booking platform built end to end. Spring Boot REST API backend, React frontend, MySQL database, containerized with Docker, and a GPT-4 chatbot for intelligent scheduling assistance.

`Java` `Spring Boot` `React` `MySQL` `Docker` `OpenAI API`

---

### [Tally](https://github.com/Yameen05/Tally) — Personal Finance Dashboard

Full-stack finance dashboard for tracking transactions, planning monthly budgets, and understanding where your money actually goes. Connects to real bank accounts via Plaid, exports CSV, and surfaces AI-powered spending insights when an OpenAI key is configured. Spring Boot + React + MySQL, fully containerized.

`Java` `Spring Boot` `React` `TypeScript` `MySQL` `Docker` `Plaid` `OpenAI API`

---

### [Verdict](https://github.com/Yameen05/Verdict) — Multi-Agent Equity Research

Enter a ticker, get a structured Buy / Hold / Sell report. Verdict runs a LangGraph multi-agent pipeline that pulls SEC 10-K/10-Q filings (chunked and embedded into Pinecone), live news sentiment via NewsAPI + VADER, and financial metrics from yfinance. Agent progress streams to the browser in real time over SSE. Built as a software demo — not financial advice.

`Python` `FastAPI` `LangGraph` `React` `TypeScript` `Pinecone` `OpenAI` `Docker`
